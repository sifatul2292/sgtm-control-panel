Simple launch flow

Live in under 10 minutes.

No developers. No server knowledge. No DevOps. If you can update DNS, you can launch Tagioo. Here's every step, in order.

Create free account → Read the docs
Before you start: you'll need admin access to a Google Tag Manager account, DNS access for your domain (to add one CNAME record), and about 10 minutes.
01

Create account in Tagioo

Sign up at tagioo.com — takes 30 seconds. Your dashboard is ready instantly, on the Free plan (15,000 events/month, no card required).

02

Create GTM Server Container

In Google Tag Manager, create a Server container. Copy the Container Config string — you'll paste it into Tagioo next.

Point your first-party domain track.yoursite.com → bd.tagioo.com (one CNAME record)
03

Create a container in Tagioo

Paste the config, enter your domain. Tagioo handles the container, Nginx, SSL, and launch automatically — usually live within a minute or two.

04

Use Setup Assistant to download JSON files

Our 4-step wizard generates ready-made Web + Server GTM import files for GA4, Meta CAPI, Google Ads, and TikTok — pre-configured with your credentials, so you're not manually wiring up tags.

05

Import into Web & Server GTM

Upload web.json to your Web GTM container and server.json to your Server GTM container. Choose Merge, then Publish both.

06

Download plugin & connect website

Download the Tagioo WordPress plugin from Setup Assistant, install it on your WooCommerce store, and activate — it handles the full ecommerce dataLayer automatically. Not on WooCommerce? See the docs for manual dataLayer setup.

Test events in Meta

Open Meta Events Manager → Test Events. Fire a purchase on your store and watch it appear server-side. You're live — check your Tagioo dashboard for the real-time event feed.

If you get stuck on any step, our team sets it up for you via WhatsApp — free.

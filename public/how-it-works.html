Simple launch flow

A clear path to
your first event.

Bring access to your DNS, website and Google Tag Manager. Tagioo handles the hosting; this guide walks you through configuration, publishing and verification.

Create free account → Read the docs
Before you start: you'll need admin access to a Google Tag Manager account, DNS access for your domain (to add one CNAME record), and access to your website integration. Allow time for DNS propagation and testing.
01

Create account in Tagioo

Create your account and verify your email. Choose Free for 15,000 events per 30-day cycle, with no card required.

02

Create GTM Server Container

In Google Tag Manager, create a Server container. Copy the Container Config string — you'll paste it into Tagioo next.

Point your first-party domain track.yoursite.com → the DNS target provided in your container setup (one CNAME record)
03

Create a container in Tagioo

Paste the configuration and enter your tracking domain. Tagioo provisions the container and SSL; check its status before continuing.

04

Use Setup Assistant to download JSON files

Our 4-step wizard generates ready-made Web + Server GTM import files for GA4, Meta CAPI, Google Ads, and TikTok — pre-configured with your credentials, so you're not manually wiring up tags.

05

Import into Web & Server GTM

Upload web.json to your Web GTM container and server.json to your Server GTM container. Choose Merge, review the imported configuration and test in Preview before publishing both.

06

Connect your website

Download the Tagioo WordPress plugin from Setup Assistant, install it on your WooCommerce store, and activate — it handles the full ecommerce dataLayer automatically. On Shopify, follow the Custom Pixel or app connection instructions in Setup Assistant, using one integration path. For Laravel or custom sites, follow the platform guide.

Verify events end to end

Preview your GTM containers and place a test order. Inspect the request in Tagioo, then verify the event and deduplication in Meta, GA4 or your other selected destinations.

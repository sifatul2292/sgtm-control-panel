Before you read your report

Does “Not observed” mean tracking is broken?

No. This checker reads public HTML and up to three same-origin JavaScript files. It does not run JavaScript, accept cookies, log in, or inspect tags loaded by external containers. Use GTM Preview and your destination’s test-event tools to confirm actual behavior.

Can you verify server-side tracking?

We look for first-party loader URLs and server transport configuration. These are implementation clues. Only a real event in Server GTM Preview and acceptance in GA4, Meta or another destination can confirm delivery.

Why isn’t there a tracking quality score?

Counting tags is not a measure of tracking quality. The report shows how many visible checks were observed, the evidence behind them, and what to verify. It does not estimate lost conversions, ad-spend impact or browser cookie lifetime.

What happens to my scan?

Reports are temporarily cached in server memory for up to five minutes and are not saved to customer accounts. Website URLs are sent to Tagioo’s server to retrieve the public page. Cookie values and raw page source are not included in the report. Download a JSON copy or print your report if you want to keep it.

What if the site blocks the scan?

Some websites reject automated requests or serve a challenge page. Try a different public page, or inspect the site in your browser’s developer tools. Private networks, custom ports and oversized responses are blocked.

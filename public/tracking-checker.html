What the checker looks for

Server-side tracking

Is your data sent through a server container on your own domain, and is that server actually live?

Browser-only pixels

Meta, TikTok, GA4 and Google Ads tags that rely only on the browser, where ad blockers and Safari drop events.

Duplicate tracking

Pixels installed twice (theme code, apps, plugins and GTM) that double-count purchases.

Google Ads setup

Conversion tags, the conversion linker and enhanced conversions.

Ecommerce events

Purchase and product events for Shopify, WooCommerce and other stores.

Consent & loading

Cookie banners, Google Consent Mode and whether GTM loads from your own domain.

Unlike most free checkers, we open your published GTM container and test your server container, instead of only searching the page's HTML.

Questions about the checker

How does the checker work?

It loads your page, reads the scripts on it, opens your published Google Tag Manager container to see every tag inside, reads Shopify app pixels, and pings your server container's health check. Most free checkers only look at the HTML, so they miss everything that loads through GTM.

Can it tell if I have server-side tracking?

Yes, when your Google tag sends data to a server container we can see the URL and test that the container is live. Server containers are private, so we can confirm one is running but not every tag inside it — for Meta, check Events Manager for events marked “Server”.

Can it see Meta Conversions API (CAPI)?

Not directly. CAPI runs server to server, so no browser-based checker can see it. We report it as “possible” when a live server container, a server-side app (like Elevar) or Shopify's Meta channel is present, and tell you where to confirm it.

How is the score calculated?

Every site starts at 100. Each issue removes points by severity: critical 25, high 14, medium 7, low 3. If we can't see a site's tracking (for example a JavaScript app or a site that waits for cookie consent), we say so instead of guessing a score.

Why didn't it find my tracking?

Some sites load tags only after cookie consent, inside a JavaScript app, or on checkout pages we can't open. Try scanning a product or landing page, or email hello@tagioo.com for a free manual review.

What happens to my scan?

Reports are kept in server memory for up to five minutes and aren't saved to an account. We don't store page source or cookie values, and we never send test events to your platforms.
